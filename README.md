# ImmoHub
## Nebenkosten (neu)
Web-Version der Vermieter-App: Nebenkostenabrechnung mit Umlageschlüsseln, Heizkosten (HeizkostenV, CO₂-Aufteilung), Zählerständen inkl. Zählertausch, Kaltmiete und Mietverlauf, Vorauszahlungs-Anpassung, Fristen (§ 556 BGB), Belegablage, Leerstand, Kaution, Mieterwechsel und Anlage-V-Übersicht. Daten bleiben auf dem Gerät. Backup unter „Mehr“. Tests: `node nebenkosten/tests/logik.test.js`.
